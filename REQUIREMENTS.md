Описание системы
Система "Умный список задач" — это цифровой инструмент для управления личными или командными задачами. Она позволяет пользователям создавать, редактировать и удалять задачи, а также организовывать их с помощью приоритетов, категорий, дедлайнов и напоминаний. Система предоставляет удобные функции поиска и фильтрации, чтобы пользователь мог быстро находить нужные задачи и сосредоточиться на важных делах.

Функциональные требования
1. Создание, редактирование, удаление задач
Пользователь может создать новую задачу, указав заголовок, описание, дедлайн (опционально) и другие параметры.
Пользователь может отредактировать любое поле существующей задачи.
Пользователь может удалить задачу из списка.
2. Приоритеты задач
Каждая задача может иметь один из трёх уровней приоритета: низкий, средний, высокий.
Приоритет визуально выделяется (например, цветом или значком) для быстрого распознавания.
3. Категории задач
Пользователь может назначать задачам категории (например, "Работа", "Личное", "Учеба").
Возможность создавать, редактировать и удалять пользовательские категории.
4. Поиск и фильтрация
Пользователь может искать задачи по ключевым словам в заголовке или описании.
Возможность фильтрации задач по:
Приоритету
Категории
Статусу (выполнено/не выполнено)
Дедлайну (ближайшие, просроченные, все)
5. Дедлайны и напоминания
К каждой задаче можно установить дедлайн (дата и время).
Система отправляет напоминание пользователю за заданное время до дедлайна (например, за 1 час, за 1 день).
Напоминания могут быть встроенным уведомлением в приложении или через внешние сервисы (email, push-уведомления).

User Stories
1. Как студент,
я хочу устанавливать приоритеты для своих задач (например, "высокий" для экзаменов, "низкий" для хобби),
чтобы всегда видеть, на чём мне нужно сфокусироваться в первую очередь.
2. Как менеджер проекта,
я хочу фильтровать задачи по категориям (например, "Разработка", "Тестирование", "Документация"),
чтобы быстро оценивать прогресс по каждому направлению и перераспределять нагрузку.
3. Как занятой человек,
я хочу получать напоминания о предстоящих дедлайнах (например, за день до события),
чтобы не забыть важные дела и успевать выполнять задачи в срок.
