Архитектура системы "Умный список задач"
Описание архитектуры
Система реализована как монолитное веб-приложение — все компоненты (frontend, backend и база данных) работают в рамках одного приложения и развертываются вместе. Это упрощает разработку, тестирование и развертывание на начальных этапах проекта.

    Frontend: Отвечает за пользовательский интерфейс. Реализован с использованием HTML, CSS и JavaScript (возможно, с использованием легковесных фреймворков, таких как Alpine.js или vanilla JS).
    Backend: Обрабатывает бизнес-логику, взаимодействует с базой данных и предоставляет API для frontend. Реализован на Python с использованием фреймворка Flask.
    Database: Хранит данные о задачах, категориях, приоритетах и напоминаниях. Используется SQLite — легковесная встраиваемая СУБД, идеально подходящая для монолитного приложения с низкой нагрузкой.

Основные API endpoints
Все API-запросы от frontend к backend будут отправляться на /api/ с соответствующими методами HTTP.

Задачи
GET /api/tasks — Получить список всех задач (с возможностью фильтрации через query-параметры)
GET /api/tasks/<int:task_id> — Получить одну задачу по ID
POST /api/tasks — Создать новую задачу
PUT /api/tasks/<int:task_id> — Обновить существующую задачу
DELETE /api/tasks/<int:task_id> — Удалить задачу
Категории
GET /api/categories — Получить список всех категорий
POST /api/categories — Создать новую категорию
PUT /api/categories/<int:category_id> — Обновить категорию
DELETE /api/categories/<int:category_id> — Удалить категорию
Поиск и фильтрация
GET /api/tasks?search=...&priority=...&category=...&deadline=... — Фильтрация задач по параметрам (поиск, приоритет, категория, дедлайн)
Напоминания (опционально)
GET /api/reminders — Получить список напоминаний (например, задачи с дедлайнами на сегодня/завтра)
POST /api/reminders — Установить напоминание для задачи (если не привязано автоматически к дедлайну)
