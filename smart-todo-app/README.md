# Умный список задач — Smart Todo App

> Монолитное веб-приложение для управления задачами с приоритетами, категориями, дедлайнами и напоминаниями.

## 🎯 Описание

**Smart Todo App** — это простой, но мощный инструмент для организации личных и рабочих задач. Приложение позволяет:

- Создавать, редактировать и удалять задачи.
- Назначать приоритеты: низкий, средний, высокий.
- Группировать задачи по категориям.
- Искать и фильтровать задачи по ключевым словам, приоритету, категории или дедлайну.
- Устанавливать дедлайны и получать напоминания.

Приложение разработано как монолит на Python (Flask) + HTML/CSS/JS, с использованием SQLite в качестве базы данных.
